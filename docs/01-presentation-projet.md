# Présentation du projet

## Nom

Spoilifly Mobile

## Contexte

Spoilifly Mobile est une application Flutter qui reprend le concept du projet web `spoilifly` en version téléphone. L'application consomme la même API que la version web et s'appuie sur le même modèle de données.

## Problème métier

L'application répond à un besoin de consultation et de gestion de contenus premium liés à des oeuvres culturelles :

- découvrir des oeuvres
- consulter des spoilers classés par niveau
- accéder à une bibliothèque personnelle
- gérer une authentification utilisateur

## Nature de l'application

L'application n'est pas une simple todo list générique. Elle se place sur un cas métier concret : une plateforme de contenus premium autour de spoilers, packs et bibliothèque utilisateur.

## Objectifs principaux

- proposer une interface mobile cohérente avec le projet web existant
- réutiliser l'API `spoilifly`
- structurer l'application avec des widgets réutilisables
- mettre en place une navigation claire entre plusieurs écrans
- documenter le projet proprement

## Ecrans principaux

- accueil / onboarding
- connexion / inscription
- accueil applicatif
- catalogue
- bibliothèque
- profil
- détail d'oeuvre
- détail de spoiler

## Réponse au référentiel

Le projet couvre les attendus suivants :

- charte graphique définie
- plusieurs écrans avec navigation
- système d'authentification
- lien avec une API
- documentation technique et fonctionnelle

## Suite logique du projet

- compléter les opérations CRUD liées aux entités métier
- enrichir les parcours autour des messages, meetings, checkout et créateur
- améliorer la résilience réseau et les états d'erreur
